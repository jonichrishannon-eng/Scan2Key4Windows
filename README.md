## Tutorial
Step 1. (prerequisites):
  <br>
Download QRServ (newest release recomended!) from github and/or Google play store with the following link;
<a href="https://github.com/uintdev/qrserv">Download QRServ here</a>
<br>
Install the .apk file/app to a supported Android Device and run it
<br>
Step 2. (Creation of a Local/Personal network to share files):
Connect the PA700 via Wifi-Hotspot to the Device you just downloaded QRServ on
